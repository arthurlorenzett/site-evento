# Mutirão Dev 2027: site de evento com inscrições

## Tecnologias

| Parte | Tecnologia | Versão |
|---|---|---|
| Backend | Node.js | 22.13 ou mais novo |
| | Express | 5.3 |
| | SQLite (`node:sqlite`, nativo do Node) | — |
| Frontend | React | 19.3 |
| | React Router | 8.5 |
| | Vite | 8.3 |

## Como rodar

Backend (porta 3001):

```bash
cd backend
npm install
npm run dev
```

Frontend (porta 5173), em outro terminal:

```bash
cd frontend
npm install
npm run dev
```

Acesse `http://localhost:5173`.
